# 📐 Geometrical Algorithms in C++

A collection of essential **Computational Geometry algorithms** implemented in C++.
This repository is designed for students, developers, and competitive programmers who want to learn, analyze, or reuse geometry algorithms in projects.

It includes classic geometric techniques such as **Convex Hull**, **Closest Pair**, **Line Intersection**, **KD-Trees**, **Sweep Line**, **Divide & Conquer**, and more.

---

## 🚀 Features

* Clean and modular C++ implementations
* Covers a wide range of geometry problems
* Suitable for:

  * Competitive programming (ICPC, Codeforces, LeetCode)
  * Academic assignments
  * Research and algorithm analysis
* Easy to understand & modify

---

## 📂 Algorithms Included

### 🔹 **Convex Hull Algorithms**

* `GrahamScan.cpp`
* `JarvisMarch.cpp`

### 🔹 **Closest Pair of Points**

* `ClosestPair.cpp`
* Uses Divide & Conquer (O(n log n))

### 🔹 **Line & Segment Algorithms**

* `INTERSECTION.cpp` – Line/segment intersection detection
* `SweepLineAlg.cpp` – Sweep Line Algorithm

### 🔹 **KD-Tree Algorithms**

* `KDtreePartition_RangeSearching.cpp`
* `kd2.cpp`
* `kdSeaching.cpp`

### 🔹 **Divide & Conquer Algorithms**

* `Divide&Conquer.cpp`
* `d_q.cpp`

### 🔹 **TSP (Travelling Salesman Problem)**

* `TSP.cpp` – Geometric heuristics / optimization

### 🔹 **Load Balancing Algorithm**

* `Load_Balancing.cpp`

### 🔹 **Miscellaneous**

* `ASSIGN9.cpp`
* `s.cpp`
* `tempCodeRunnerFile.cpp`

## 📦 How to Compile & Run

### Compile

```bash
g++ filename.cpp -o output
```

### Run

```bash
./output
```

Example:

```bash
g++ GrahamScan.cpp -o hull
./hull
```
